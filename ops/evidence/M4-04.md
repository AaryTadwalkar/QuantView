## 2. Mathematical Strike Selection Rules

Given underlying spot price $S_{\text{spot}}$ and available strikes sorted ascending $K = \{k_1, k_2, \dots, k_n\}$:

1. **ATM Strike:**
   $$k^* = \arg\min_{k \in K} \left(|k - S_{\text{spot}}|, k\right)$$
   *(Ties broken deterministically towards lower strike)*

2. **Call Option (CE) Moneyness:**
   - **ITM Depths:** $K_{\text{ITM}} = [k \in K \mid k < k^*]$ sorted descending (closest to ATM first).
     $$\text{ITM}_d = K_{\text{ITM}}[d - 1] \quad \text{for } 1 \le d \le |K_{\text{ITM}}|$$
   - **OTM Depths:** $K_{\text{OTM}} = [k \in K \mid k > k^*]$ sorted ascending (closest to ATM first).
     $$\text{OTM}_d = K_{\text{OTM}}[d - 1] \quad \text{for } 1 \le d \le |K_{\text{OTM}}|$$

3. **Put Option (PE) Moneyness:**
   - **ITM Depths:** $K_{\text{ITM}} = [k \in K \mid k > k^*]$ sorted ascending (closest to ATM first).
     $$\text{ITM}_d = K_{\text{ITM}}[d - 1] \quad \text{for } 1 \le d \le |K_{\text{ITM}}|$$
   - **OTM Depths:** $K_{\text{OTM}} = [k \in K \mid k < k^*]$ sorted descending (closest to ATM first).
     $$\text{OTM}_d = K_{\text{OTM}}[d - 1] \quad \text{for } 1 \le d \le |K_{\text{OTM}}|$$

4. **Zero Substitution Guard:**
   $$\text{If } d > |K_{\text{policy}}| \implies \text{return } \text{NO\_ELIGIBLE\_CONTRACT}$$
