## 2. API Health & Heartbeat Endpoints

QuantView provides two dedicated health endpoints served by the FastAPI gateway:
1. `GET /api/v1/health`:
   - Returns gateway status (`healthy`), UTC timestamp, DuckDB lake connection status, and version.
   - Verified SLA: $\le 15\text{ ms}$ response latency.
2. `GET /api/v1/health/heartbeat`:
   - Inspects telemetry heartbeat files under `Data/raw/telemetry/`.
   - Surfaces last tick arrival, data freshness, and staleness alerts ($> 60\text{ s}$ lag during market hours).

Both endpoints are covered by automated unit tests in `tests/api/test_health_and_setup.py` and pass 100%.
