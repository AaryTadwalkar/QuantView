## 2. Deliverables Summary

1. **`services/collector_snapshot/token_manager.py`:**
   - Implements `TokenManager`, `TokenState` (`VALID`, `WAITING_FOR_TOKEN`, `EXPIRED`, `MISSING_TOKEN`), and `TokenCheckResult`.
   - Native JWT payload parsing without third-party dependencies.
   - Enforces 08:45 AM Asia/Kolkata pre-flight gate. Dispatches alert on auth failure.

2. **`services/collector_snapshot/heartbeat.py`:**
   - Implements `HeartbeatMonitor`, `HeartbeatEmitter`, `HeartbeatRecord`, and `MissingHeartbeatAlert`.
   - Manages atomic telemetry files under `Data/raw/telemetry/`.
   - Dead-man switch freshness evaluation enforcing maximum 60.0s gap threshold.

3. **`tools/ops/check_token_readiness.py`:**
   - Standalone CLI utility for morning automation and systemd timers.
   - Outputs human-readable status or machine-readable JSON. Exits 0 on valid, 1 on waiting/expired.

4. **`services/collector_snapshot/__init__.py`:**
   - Re-exports `TokenManager`, `TokenState`, `TokenCheckResult`, `HeartbeatMonitor`, `HeartbeatEmitter`, `HeartbeatRecord`, and `MissingHeartbeatAlert`.

5. **`tests/unit/test_token_and_heartbeat.py`:**
   - 10-test suite verifying token validation, expiration parsing, WAITING_FOR_TOKEN states, atomic pulse writes, missing/stale alerts, and CLI exit codes.
