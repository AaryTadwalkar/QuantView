## 1. Acceptance Contract Evaluation

| Acceptance Requirement | Status | Verification & Evidence Method |
|---|---|---|
| **Raw-First Ingestion Priority** | **PASS** | Raw HTTP response bytes are compressed with `gzip`, written to `.tmp`, flushed, and synced via `os.fsync()` before any downstream decoding or normalization begins. |
| **Atomic Manifest Publication** | **PASS** | Companion `capture_<id>.manifest.json` is written with atomic rename and `fsync`. Records `uncompressed_sha256`, `compressed_sha256`, byte sizes, timestamps, and HTTP metadata. |
| **Zero Capture Loss on Decoder Failure** | **PASS** | Verified by `test_raw_retained_on_decoder_parse_failure`: corrupted/truncated JSON streams trigger `DECODER_PARSE_ERROR` in manifest, but raw `.json.gz` payload remains 100% intact, durable, and bit-exact on disk. |
| **Resilient REST Adapter** | **PASS** | `UpstoxSnapshotAdapter` supports exponential backoff with jitter on 429/5xx, fail-closed handling on 401/403 (zero wasted quota), and deterministic session mocking. |
| **Secret Redaction** | **PASS** | Verified by `test_secret_redaction_in_repr`: access tokens and auth headers are never logged or revealed in `__repr__` / string representations. |
| **Forensic Reconciliation Auditing** | **PASS** | Verified by `test_raw_to_manifest_reconciliation_valid` and `test_raw_to_manifest_reconciliation_detects_defects`: `reconcile_session_directory()` checks 1:1 raw-to-manifest matching and verifies SHA-256 hashes of uncompressed payloads. |
| **Dynamic Expiry Resolution** | **PASS** | Eliminates legacy hardcoded expiry dates; dynamically resolves nearest future weekly/monthly expiry from `config/nse_nifty_expiries_2025_2026.json`. |

## 2. Deliverables Summary

1. **`services/collector_snapshot/raw_writer.py`:**
   - Implements `RawSnapshotWriter` and `RawCaptureRecord`.
   - Manages directory layout: `Data/raw/upstox_rest/snapshots/trade_date=YYYY-MM-DD/capture_<id>.json.gz` and companion `.manifest.json`.
   - Guarantees crash-resilient write order: write `.tmp` -> `flush()` -> `os.fsync()` -> atomic `rename()`.
   - Computes independent SHA-256 hashes on uncompressed response bytes and compressed file on disk.
   - Provides non-destructive `update_manifest_decoder_status()` and forensic `reconcile_session_directory()`.

2. **`services/collector_snapshot/adapter.py`:**
   - Implements `UpstoxSnapshotAdapter` and `SnapshotResponsePayload`.
   - Handles HTTP communication, socket timeouts (10.0s), retry loops with exponential backoff and jitter on 429/5xx.
   - Immediate fail-closed on 401 Unauthorized / 403 Forbidden to protect quota and halt invalid sessions.
   - Strict token masking in string representations.
   - Supports mock session dependency injection for hermetic offline tests.

3. **`services/collector_snapshot/collector.py`:**
   - Implements `SnapshotCollectorService` and `generate_snapshot_id()`.
   - Orchestrates the raw-first workflow: fetch raw bytes -> generate deterministic ID (`snap_YYYY-MM-DD_HHMMSS_<sha[:8]>`) -> persist raw payload & manifest -> attempt decoding with error boundary -> update manifest status.
   - Fully decouples raw capture durability from decoder success.

4. **`services/collector_snapshot/__init__.py`:**
   - Exports `RawSnapshotWriter`, `UpstoxSnapshotAdapter`, `SnapshotCollectorService`, `SnapshotResponsePayload`, and `RawCaptureRecord`.

5. **`tests/unit/test_collector_snapshot.py`:**
   - Comprehensive 12-test suite verifying durability, atomic staging, hash matching, decoder failure resilience, secret masking, and reconciliation auditing.
